Three modes, three jobs

Every lesson shares one set of animated scenes. The modes differ in how they walk you through them.

🎧 Narrated

default

The course itself. A voice explains, the visuals move with it, and it stops for your taps and choices. Becomes a lesson’s default once its narration is complete.

▶ Guided

later

Silent and self-paced, with more detailed written explanations. Regenerated lesson by lesson after the narration exists.

Explore

reference

Free-form labs, cheat sheets, and drill answers for review before an interview.

One story: the bakery grows up

Each level is a stage of Maya’s bakery, so every new concept arrives as the business’s next real problem. Topics are drawn from Designing Data-Intensive Applications (DDIA) and Database Internals (DI); explanations are the course’s own.

Level 1 · the notebook

Foundations

One shop. SQL, data models, measuring systems: Maya’s two phone numbers, Ana’s lost order.

Level 2 · one server

Inside one database

The bakery goes online. Storage engines, indexes, queries, transactions: slow order history, double-sold pickups.

Level 3 · a chain

Distributed data

Stores in many cities. Replication, sharding, failures, consensus: conflicting edits, clock skew, split brain.

Level 4 · the platform

Data systems

Analytics and a delivery app. Caching, change data capture, streams, batch, ending in the checkout incident.

Level 5 · electives

Engine depth

Cross-engine indexing, B-tree variants, latches, for roles that go deep.

Build order

Statuses come from docs/roadmap/data.js; edit it and this page updates within a few seconds. Every lesson stays within 8–12 minutes, 3 big ideas and 8 keywords. New lessons are tiered by interview value: T1 first.

Audio hosting

Audio streams one line at a time, with the next two lines prefetched, and lives outside the repository.

GitHub Pages before

  • 1 GB site, about 100 GB a month
  • Audio lived in the main repo, so every clone got heavier

Cloudflare Worker live

  • Assets-only Worker nout-audio, deployed by voice.py deploy
  • Free: 20,000 files, 25 MiB each
  • Voice encoded at 40 kbps mono

Cloudflare R2 if it outgrows

  • 10 GB free, no egress fees
  • Usually needs a card on file
  • Its free r2.dev address is rate-limited; production needs your own domain
